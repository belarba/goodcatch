# Purse Net Phase A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the purse net a real dilemma (protected animals refuse buoys), only deal deep maps, and pull the player back with stars and a clue.

**Architecture:** Rules and pure helpers (`canBuoy`, `stars`, `clueFor`) live in `@gen` so Node tests them; the solver mirrors the rule; curation happens offline in `tools/solve-net.mjs`, which records the chosen generation seed in `CARD_REF` rows (`{s?, c}`) that the page generates from.

**Tech Stack:** static `index.html`, Node dev tools with `highs`.

**Spec:** `docs/superpowers/specs/2026-09-29-net-depth-design.md`

## Global Constraints

- A buoy on a protected animal (`SP[sp].p < 0`) is refused unless the card is Release (`card.release`).
- Release's rule text: "Buoys may sit on protected animals: +3 each" / "Boias podem ficar sobre protegidos: +3 cada".
- Stars against the map's exact best: ★ ≥ 70%, ★★ ≥ 85%, ★★★ = 100%.
- Curation: `MAX_VARIANTS` = 10, `DEEP` starts at 0.80 and is calibrated before the full run.
- `CARD_REF` rows: `{"s": "<generation seed>", "c": [trio]}`, `s` omitted when equal to the key. The trio is still dealt from `<key>:trio`.
- Every UI string in `STR.en` and `STR.pt`; comments only on critical lines; no `Co-Authored-By`.
- Numbers in commits and the final report come from commands run in the same turn.

### Task 5: I2 clue

**Files:** `index.html` (`@gen`: `clueFor`; `renderResult`; STR), `tools/depth.mjs` (checks).

**Interfaces:** `clueFor(g, bestMarks: Set<number>) → null | {k:'prot', sp} | {k:'reef', dir} | {k:'species', sp, n, m} | {k:'side', dir}`; `dir ∈ 'n'|'s'|'e'|'w'`.

- [ ] **Step 1: Checks** in `depth.mjs` (hand-built boards on an 11×11 sea, boat at (5,5)):
  - prot: player's pen holds a turtle, best's does not → `{k:'prot', sp:'tartaruga'}`.
  - reef: best pen borders rocks north of the boat, player's borders none → `{k:'reef', dir:'n'}`.
  - species: same pen side, best has 3 sardines, player 1 → `{k:'species', sp:'sardinha', n:3, m:1}`.
  - side: best pen south, player's north, no other rule → `{k:'side', dir:'s'}`.
  - equal pens → `null`.
- [ ] **Step 2: Implement** `clueFor` in `@gen`:

```js
function clueFor(g,bestMarks){
  const mine=evaluateBuoys(g); if(!mine.hits) return null;
  const saved=g.marks; g.marks=bestMarks; const best=evaluateBuoys(g); g.marks=saved;
  if(!best.hits) return null;
  const count=hits=>{const m={};for(const [r,c] of hits){const sp=g.grid[r][c].sp;m[sp]=(m[sp]||0)+1}return m};
  const cm=count(mine.hits), cb=count(best.hits), [sr,sc]=g.start;
  const dir=cells=>{let dr=0,dc=0;for(const k of cells){dr+=Math.floor(k/100)-sr;dc+=k%100-sc}return Math.abs(dr)>=Math.abs(dc)?(dr<0?'n':'s'):(dc<0?'w':'e')};
  for(const sp in cm) if(SP[sp].p<0&&!cb[sp]) return {k:'prot',sp};
  const reef=inside=>{const s=new Set();for(const k of inside){const r=Math.floor(k/100),c=k%100;for(const [dr,dc] of [[1,0],[-1,0],[0,1],[0,-1]]){const nr=r+dr,nc=c+dc;if(nr>=0&&nc>=0&&nr<g.rows&&nc<g.cols&&g.grid[nr][nc].rock)s.add(key(nr,nc))}}return s};
  const rb=reef(best.inside), rm=reef(mine.inside);
  if(rb.size){const d=dir(rb);if(![...rm].length||dir(rm)!==d) return {k:'reef',dir:d}}
  let top=null; for(const sp in cb){const miss=cb[sp]-(cm[sp]||0);if(SP[sp].p>0&&miss>0&&(!top||miss>top.n-top.m))top={k:'species',sp,n:cb[sp],m:cm[sp]||0}}
  if(top) return top;
  const db=dir(best.inside); if(dir(mine.inside)!==db) return {k:'side',dir:db};
  return null;
}
```
